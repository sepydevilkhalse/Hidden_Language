# 📢 پیام به کاربران

سلام! 👋

هر وقت این فایل رو تغییر بدی و توی گیت‌هاب Commit کنی، محتوای همینجا توی پنل «پیام‌ها»ی برنامه به همه کاربرا نشون داده میشه.

## چطور پیام جدید بفرستم؟

فقط همین متن رو پاک کن و پیام خودت رو بنویس، بعد Commit کن. همین!

## قالب‌بندی که پشتیبانی میشه

- **متن پررنگ** با دو ستاره دو طرفش
- *متن مورب* با یک ستاره دو طرفش
- لیست‌ها با خط تیره در اول خط
- [لینک](https://example.com) با این فرمت
- خط جداکننده با سه تا خط تیره پشت سر هم در یک خط جدا (---)

---

از این خط به پایین رو می‌تونی به عنوان یادداشت نگه داری یا پاک کنی.
